Del prototipo a producción

Quien conoce el proceso lo prototipa en Cowork y ese prototipo entra en la Fábrica. Sale convertido en un módulo real de la plataforma corporativa — con API, base de datos, roles y deploy — sin tocar git, CLI ni infraestructura.

Arquitectura · 02 / 02

Dos sistemas: la Fábrica que produce y la Plataforma que opera

Un solo frontend, una sola API y una sola base de datos para toda la organización. Cada prototipo aprobado se convierte en un módulo aislado dentro de esa plataforma — nunca en otra app suelta.

La Fábrica

awkfactory
Control plane
Produce los módulos
Conector MCP OAuth · sin tokens que repartir
Puerta de entrada desde Cowork. 6 tools cubren enviar, aprobar, consultar y pedir cambios. El acceso lo da el login corporativo, no el plugin.
API de la Fábrica NestJS
Proyectos, specs versionadas, gates y auditoría de quién aprobó qué. Expone el dashboard de seguimiento con timeline y preview links.
Runners de generación Claude Agent SDK headless
Contenedores efímeros con el monorepo clonado: rellenan la plantilla de módulo según la spec aprobada, ejecutan build y tests, y abren PR. Cola BullMQ + Redis.
Verificación y gobernanza CI + revisión
Typecheck, lint de fronteras entre módulos, tests y migraciones contra BD efímera. Revisión humana obligatoria si hay datos sensibles, migraciones compartidas o alta complejidad.

La Plataforma

awkplatform
Producto
Opera el día a día
Shell web React + Vite · Tailwind + shadcn/ui
Una única aplicación con la identidad Awakelab. El menú y las rutas se construyen según el rol de cada persona y los manifests de los módulos instalados.
Core común se construye una vez, a mano
Autenticación, RBAC, usuarios, auditoría, notificaciones y componentes de marca. Es lo que elimina la duplicación entre departamentos.
Módulos generados API NestJS · modules/
Un prototipo = un módulo aislado en su carpeta y su schema. Solo puede hablar con el core y con otros módulos por sus APIs públicas — regla verificada por lint en CI.
Datos PostgreSQL 16 + Prisma
Schema core + un schema por módulo, con relaciones reales y migraciones versionadas. Row-Level Security para lo confidencial: la clasificación de la spec se vuelve política ejecutable.
